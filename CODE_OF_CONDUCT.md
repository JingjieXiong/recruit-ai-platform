# Code of conduct

## Our standard

Be respectful, specific, and constructive. Disagreement about product, policy, evidence, or implementation is welcome; harassment, discrimination, intimidation, and disclosure of private data are not.

This project works with sensitive recruiting workflows. Contributors must not post real candidate data, credentials, private interview material, or identifying screenshots.

## Enforcement

Report conduct concerns through the repository's private maintainer contact or GitHub reporting tools. Maintainers may edit or remove content and restrict participation when necessary to protect people and the project.

This concise policy should be replaced with an organization-approved code of conduct before opening broad public contributions.
